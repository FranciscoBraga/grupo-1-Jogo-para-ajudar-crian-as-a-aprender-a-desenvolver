# robokids

jogo pra criança aprende programar

## instalar

```
pip install flask==0.10 sqlite3
```

rode com

```
python main.py
```

e abre no http://localhost:8000

## como jogar

arrasta os blocos pra montar o programa e clica em rodar. tem 10 fases.

o jogo tbm tem modo multiplayer e salva no banco postgres

## usuario padrão

admin / admin
